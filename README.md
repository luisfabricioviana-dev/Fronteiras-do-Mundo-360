# Fronteiras do Mundo 360

Repositório canônico das regras, perfis, referências, regressões e extensões específicas do projeto **Fronteiras do Mundo 360**.

## Escopo

Este repositório contém apenas capacidades e configurações específicas do profile/canal. Capacidades genéricas e reutilizáveis entre canais permanecem no repositório `agente-youtube`.

## Regra de fronteira

- `agente-youtube` = core compartilhado e capacidades reutilizáveis.
- `Fronteiras-do-Mundo-360` = identidade, regras, geografia, QA, referências, regressões e extensões específicas do canal.
- `prompt-agent-compiler` = compilação e runtime genéricos de prompts/agentes.
