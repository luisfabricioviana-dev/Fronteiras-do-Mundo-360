# Reference Style Library — FDM360

Biblioteca de referências audiovisuais específicas do Fronteiras do Mundo 360.

## Governança

- `REFERENCE_ONLY` não significa identidade fixa do canal.
- `NEW VIDEO != NEW RULE`.
- Técnicas extraídas precisam sobreviver a comparação, regressão e gate de promoção.
- Fingerprints, style memory e performance memory permanecem isolados neste profile.

## Conteúdo esperado

- fingerprints de referências
- técnicas narrativas reutilizáveis
- técnicas visuais e de edição
- padrões de retenção
- limitações e condições de uso
- status de promoção/rejeição
